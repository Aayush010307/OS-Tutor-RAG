## Direction contract

THESIS: A study desk, not a chatbot. The conversation is a lesson with a visible state machine; the category default (centered chat column, floating composer, nothing else) is refused in favour of a lesson that shows where it is and where each claim came from.

OWN-WORLD: Cool charcoal ground, a darker side rail, one restrained cobalt accent for action and the current state, semantic green/amber/red only for analysis. Atkinson Hyperlegible Next for all text, Atkinson Hyperlegible Mono for code and citation refs. Hairline borders, 8px controls, 12px messages and panels, 14px composer, no cards around messages.

STORY: The student asks, sees the tutor diagnose first, answers in their own words, follows an explanation whose every [S] chip opens the exact slide or page, and sees the lesson close. The evaluator flips one switch to see the tutor's judgement of each answer.

FIRST VIEWPORT: Left rail (brand, New lesson, local history, settings). Header: lesson title, model, and the stage rail. Main: welcome with four real starter questions; composer at the bottom. Sources panel on the right at xl once a lesson exists (nothing is retrieved before the first question), drawer below.

FORM: Signature move: the stage rail drawn as the process state diagram OS students know (hollow, visited and lit state nodes on hairline transition edges; a Check-to-Explain return arc carrying the round count; the edge into a new state draws itself once).
